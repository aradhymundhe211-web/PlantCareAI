PlantCare AI — audit and validation report
Audit date: 2026-10-18
Repository: aradhymundhe211-web/PlantCareAI (main)

Scope
- Reviewed source code and data files, the seven Streamlit navigation pages, plant identification flow, model hints, reference-image lookup, care tools, and session-state features.
- The deployed Streamlit UI could not be fully exercised through the available browser inspection. Static code checks are not a substitute for live browser testing.

Confirmed from source
- plant_data.json contains 56 unique common names and 56 unique scientific names.
- MODEL_HINTS now contains one non-empty entry for each of the 56 species.
- Identification uses BioCLIP 2 first and the original BioCLIP as a fallback, with prompt-based ranking across image views. This is zero-shot ranking, not a custom-trained 56-class model.
- Camera and gallery inputs share the same image-analysis pipeline after image decoding and orientation correction.
- Non-plant safeguards include a MobileNetV3-Small ImageNet object screen, BioCLIP plant/object comparisons, and a document-like-image heuristic.
- Plant-health screening is based on approximate image colour patterns, not a trained disease detector or leaf-segmentation model.
- Copilot answers are profile-grounded and rule-based, not generated by a general-purpose AI model.
- My Plants, reminders, and journal entries are currently session-scoped and are not guaranteed to persist across sessions or restarts.

Changes made in this audit
- Removed the ImageNet label “vase” from hard non-plant rejection because real potted plants can trigger that label.
- Reordered analysis views so a vegetation-focused crop is included among the first two views used by the fast object screen.
- Changed object rejection to require stronger repeated evidence across views, except for very strong object scores.
- Moved the BioCLIP plant/object check to one pre-ranking pass. Ambiguous BioCLIP evidence now proceeds to species ranking; decisive object/document evidence can still be rejected.
- Removed duplicate Tulsi and Mint keys from MODEL_HINTS.
- Replaced boilerplate identification and leaf descriptions with species-specific visual clues derived from each model hint. These descriptions have not been independently reviewed by a botanist.
- Added benchmark_56.py, which collects research-grade iNaturalist photos by exact scientific taxon, runs the same BioCLIP prompt/prototype ranking approach, and writes per-image predictions plus top-1/top-3 metrics to CSV.
- Added regression tests and a GitHub Actions workflow for syntax, library integrity, model-hint coverage, prompt coverage, and screening policy.
- Corrected the About page so it no longer claims optional Pl@ntNet support that is not present in this build.

Automated validation
- GitHub Actions successfully compiled app.py, plantcare_core.py, and benchmark_56.py.
- The regression suite passed 25 tests on commit a40f1211fd0062e1ab1a98deacf4c9cacc74d951. Later changes trigger another CI run; check the latest run before treating the current main branch as validated.
- These are code/data and policy tests only. They do not measure species-identification accuracy.

Not yet verified
- The real-photo 56-species benchmark has not been run; no top-1/top-3 accuracy figure is available.
- The actual live Streamlit site has not been tested end-to-end across all seven pages and interactive controls.
- The exact Mango false-rejection photo and the Fortuner Legender negative photo have not been re-tested on the live deployment after these changes.
- Car/object false-accept and plant false-reject rates have not been measured on a held-out labelled test set.
- Model checkpoint download, startup time, memory use, and CPU throttling must be checked on the actual Streamlit deployment.

How to run the real-photo benchmark locally
1. Install the project dependencies: python -m pip install -r requirements.txt
2. Run: python benchmark_56.py --per-class 2 --device cpu
3. Review benchmark_results.csv and the printed per-class top-1/top-3 metrics. Some taxa may have too few downloadable research-grade photos.
4. Separately test the live website with plant photos and non-plants. The benchmark evaluates the species ranker only; it does not certify the app's non-plant rejection or browser UI.

Accuracy claims
- Do not claim 100% accuracy or that all 56 species have passed image tests until the benchmark and live negative/positive test set have actually been run and reviewed.
