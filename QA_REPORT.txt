PlantCare AI — QA and repair report
Input: PlantCareAI-main BACKUP.zip uploaded 2026-10-18

Code findings
- plant_data.json has 56 unique common names and 56 unique scientific names.
- Model prompt hints cover every one of the 56 supported common names.
- The original model loader tried BioCLIP 2 before original BioCLIP, risking a large checkpoint download on limited hosting.
- Critical original bug: vision_gate explicitly allowed uncertain plant evidence to continue to species ranking. Several text/object checks happened after ranking and exceptions could be ignored.
- Image health analysis is colour-pattern screening, not a trained disease detector.
- Plant Health Copilot is local profile retrieval/rule-based triage, not a general LLM.
- The Pl@ntNet client files were present but not imported or called by the website; that unimplemented claim was removed along with the dead helper/test.

Changes made
- Original BioCLIP is the default to reduce memory/startup risk on free CPU hosting. BioCLIP 2 remains an explicit option via PLANTCARE_MODEL_ID after testing a stronger host. Model failure does not silently switch checkpoints or produce guessed species.
- requirements.txt now pins CPU-only PyTorch 2.5.1+cpu and torchvision 0.20.1+cpu, plus existing app packages.
- Image gating is now performed before species ranking: quality check, independent ImageNet object screen when weights are available, BioCLIP plant-vs-object check, and plant-vs-document check.
- Uncertain plant presence, obvious non-plant evidence, poor quality and unavailable model status are handled separately. A failed/uncertain gate does not flow into the 56-species ranker.
- Screening uses up to three complementary image views to reduce extra CPU work; species ranking retains multiple views.
- Removed the computed pseudo-confidence percentage. UI labels describe relative rank separation, not a calibrated probability.
- Copilot follow-up questions inherit an explicitly named plant from previous user messages, without mining assistant-generated examples.
- Added configurable screening thresholds through environment variables or Streamlit secrets.
- Corrected Python target documentation to 3.12; added deployment acceptance checklist, presentation demo guide and third-party notices.
