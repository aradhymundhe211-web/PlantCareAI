PlantCare AI — Model Notes

Primary optional model service: Pl@ntNet API
- Endpoint: https://my-api.plantnet.org/v2/identify/all
- Requires PLANTNET_API_KEY in Streamlit Secrets or the environment.
- The service returns ranked scientific taxa and scores. PlantCare AI maps results into the local 56-plant library only when scientific names match exactly after normalization.
- A result outside the supported library is not silently relabelled as a supported plant; the local BioCLIP classifier is used as a fallback.
- Pl@ntNet API service documentation: https://my.plantnet.org/doc/api/identify
- API key must never be committed to public source control. Uploaded photos are sent to Pl@ntNet when configured.

Local fallback: BioCLIP via open_clip
- Model ID: hf-hub:imageomics/bioclip
- Zero-shot text prompts cover all 56 local plant records, with multiple botanical descriptions and multi-view image scoring.
- A separate general-object screen and plant-presence prompts help reject non-plant images, but these gates can still make mistakes.
- The local fallback is not a fine-tuned classifier trained specifically on the project's 56 plant classes.

Scope and limitations
- No single model guarantees correct classification for every photo, angle, cultivar, lighting condition or plant growth stage.
- Pl@ntNet confidence scores are candidate scores, not a guarantee of correctness.
- Accuracy on the exact 56 classes must be measured using a labelled holdout set of real photos per species and a separate non-plant set.
- Tulsi vs Mint and Mango/Marigold should be tested with multiple independent photos, not just one image each.
- Never treat the Plant Health Copilot as a disease diagnosis.
