PLANTCARE AI — SAFE DEPLOYMENT CHECKLIST

Before uploading
[ ] Back up the current working GitHub repository.
[ ] Extract the supplied ZIP.
[ ] Copy the CONTENTS of PlantCareAI-main into the repository root (app.py and requirements.txt must be at the root).
[ ] Ensure .python-version contains exactly: 3.12
[ ] Replace requirements.txt as a complete file; it uses CPU-only PyTorch/torchvision wheels.
[ ] Commit the changes.

After Streamlit Cloud redeploys
[ ] Inspect deployment logs for pip dependency failures.
[ ] Inspect first model load for Hugging Face download errors, disk limits, or memory errors.
[ ] Open every app page once, especially Identify a Plant and Plant Health Copilot.
[ ] Test gallery and camera with a supported plant photo.
[ ] Test a plant leaf close-up and flower photo.
[ ] Test a car photo (including the Fortuner Legender image).
[ ] Test a screenshot of the PlantCare AI dashboard.
[ ] Test unrelated objects and a blurry/dark image.
[ ] Ask Copilot “How much light does Mango need?” then follow with “What about watering?”
[ ] Verify health results describe colour patterns and possible checks, not a confirmed disease diagnosis.

Expected outcomes
- Clear plant photographs should pass the plant-presence gate and show ranked candidates if the model loads.
- A clear car/object or screenshot should be rejected before species matching when validation models recognise it as non-plant/document content.
- Ambiguous photographs should show “Plant presence not verified” and should not receive a forced species name.
- If BioCLIP cannot load, identification should report unavailable rather than hallucinating a species.
- The Copilot follow-up can inherit a plant explicitly mentioned in the previous user message.

IMPORTANT
Policy-level unit tests do not prove the exact car or screenshot will always be rejected. Test the actual failure images on the live deployment. If any false positive remains, preserve the logs, retest both positive plant photos and negative photos, and tune thresholds against a labelled set rather than arbitrarily lowering the gate.
